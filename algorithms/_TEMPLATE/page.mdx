## Binary search is not a loop. It is a halving of a totally ordered set.

A phone book falls open near the middle. You read one name and throw away half the book. That single gesture is the algorithm, and this page is about the object it acts on: a totally ordered set and the interval of candidates still consistent with every comparison so far.

## 1 · The question

Given a sorted sequence $a_0 \le a_1 \le \dots \le a_{n-1}$ and a target `t`, return an index `i` with $a_i = t$, or report that none exists. The linear answer, scan from the left, costs up to `n` comparisons. The interesting question is how much of that work the sortedness lets you skip.

## 2 · The real object

The state is not a loop counter. It is an interval of candidate indices together with the promise that every index outside the interval is known not to be the answer. Sortedness makes that promise checkable with one comparison: if the midpoint value is too small, every index at or below it is too small.

## 3 · The mathematics

The algorithm is correct because of one invariant and one shrink:

$$ a_l \le t < a_r \qquad\text{(invariant)}, \qquad r - l \text{ at least halves each step} $$

Read the invariant as "the answer, if it exists, lies in the half-open interval". The midpoint test moves one endpoint to the midpoint, and either way the invariant survives. A bounded, strictly shrinking interval must terminate, and it can only terminate at the answer (Knuth 1973).

The cost is the number of halvings, so it is $\Theta(\log n)$. The lower bound is information-theoretic: a comparison has two outcomes, so `k` comparisons distinguish at most $2^k$ positions, and separating `n` positions needs $k \ge \log_2 n$. Binary search pays exactly the price of the information, no more.

## 4 · The payoff

The same halving appears wherever a monotone predicate splits a domain: locating a boundary in a sorted file, finding the first failing test in a bisect run, inverting a monotone function numerically, and the binary-lifting step inside balanced trees. Wherever the question is monotone, the answer costs a logarithm.
