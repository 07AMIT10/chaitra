## 1 · The question

As a task, this reads: given a weighted digraph and a source `s`, return the least total weight of a walk to a target `t`. A first course calls that a shortest path and moves on.

The run never returns a path. It finishes holding a label for every town it can reach, and the path to `t` exists only because each settled label remembers the road it arrived on. Delete the back-pointers and the run still answers the question it actually asked.

So "search" is the wrong verb. A search stops when it touches its goal; this one stops when the frontier empties, having already priced the whole reachable map.

## 2 · The real object: a vector of over-estimates and a settled set

Fix a weighted digraph with weights $w(u,v) \ge 0$, and a source $A$. Write $\delta(v)$ for the least cost of any walk from $A$ to $v$.

The state is two things: a set $S$ of **settled** vertices, and one label $d(v)$ per vertex, held to a single invariant.

$$ d(v) \;=\; \min\{\, \text{cost}(A \to v) \;:\; \text{every interior vertex of the walk lies in } S \,\} $$

Read it plainly: $d(v)$ is the cheapest way to reach $v$ when the only vertices you may pass through are the settled ones. At the start $S = \{A\}$, so each label is a direct road or $\infty$.

Two moves hold the invariant. **Settle** the unsettled vertex of least label and add it to $S$. **Relax** each outgoing road, $d(v) \leftarrow \min\bigl(d(v),\, d(u) + w(u,v)\bigr)$.

Now read the labels as over-estimates. Every label is the cost of a real walk, so $d(v) \ge \delta(v)$ at all times. Relaxation replaces $d(v)$ by the smaller of two walk costs, so the label vector falls toward the truth and can never fall through it.

That monotone decrease is the whole dynamic. Nothing else is stored.

## 3 · The mathematics: the exchange step, and the hypothesis it needs

Let $u$ be the unsettled vertex with the least label. The algorithm settles it and calls $d(u)$ final, and this section is that claim.

The argument is an induction on the settle order; assume every settled label is already final. Take any walk from $A$ to $u$ that leaves $S$ before it arrives, and let $(x,y)$ be its first road with $x$ settled and $y$ unsettled.

The walk splits at $y$. The prefix up to $y$ costs at least $d(x) + w(x,y)$, which is at least $d(y)$, because relaxing $x$ set $d(y)$ to at most that sum. The remainder runs from $y$ to $u$.

If every road has $w \ge 0$, the remainder costs at least nothing, and $y$ is unsettled, so:

$$ \text{cost}(A \to u) \;=\; \underbrace{\text{cost}(A \to y)}_{\ge\, d(y)} \;+\; \underbrace{\text{cost}(y \to u)}_{\ge\, 0} \;\ge\; d(y) \;\ge\; d(u) $$

No walk beats $d(u)$, so $d(u) = \delta(u)$ and it is final the moment it is settled. That is the greedy exchange argument of Dijkstra (1959): the settled set stays optimal, and the cheapest way out of it is optimal too.

Note where the hypothesis sits. The middle term is zero only because no road has negative weight. Make one road negative and the remainder can pull the total below $d(y)$, below $d(u)$, and the inequality collapses.

Now the algebra that names all of this. Take $\oplus = \min$ and $\otimes = +$, with identity $\infty$ for $\oplus$ and identity $0$ for $\otimes$. That is the **min-plus semiring**, the tropical semiring of the optimisation literature.

Build the weight matrix $W$ with $W_{uv} = w(u,v)$ and $\infty$ where no road exists, and $0$ on the diagonal. Then the settled vector is one row of the closure:

$$ d(v) \;=\; (W^{*})_{Av}, \qquad W^{*} \;=\; \bigoplus_{k \ge 0} W^{\otimes k} $$

The closure is the all-pairs distance matrix, and one Dijkstra run is one row of it. Floyd (1962) and Warshall (1962) compute every row with a single triple loop, and Lehmann (1977) showed that loop is a closure over any semiring. Min-plus is the case the optimisation literature calls tropical.

## 5 · The payoff: what the wavefront buys, and where it reappears

Every settle is an extract-min. Scanning all labels for the smallest costs $O(n)$ per settle and $O(n^2)$ for the run; a comparison heap brings that to $O((m+n)\log n)$ on $m$ roads. Fredman and Tarjan (1984) cut the per-road factor from $\log n$ to a constant with the Fibonacci heap, giving $O(m + n\log n)$.

Read two facts off it. The array scan tracks `n²/2` exactly, the sum of the shrinking scans. The heap tracks `n log n` up to a constant and is about 285× cheaper in comparisons at 12 800 towns.

The same triple loop read over other semirings is other algorithms. With $\oplus = \max$ it is Viterbi decoding; with edit costs it is edit distance; over $(\text{OR}, \text{AND})$ it is transitive closure. Only the two operations change.

A* keeps the settling rule and adds a goal bound to the extracted key (Hart, Nilsson and Raphael 1968). Link-state routers run this algorithm on their own maps. Contraction hierarchies precompute shortcuts so a continental road network answers in microseconds (Geisberger and others 2008).

## 6 · Advanced, and skippable: what the closure assumes

Skip this if every weight you meet is a distance.

The min-plus closure is finite exactly when no cycle has negative total weight. Around a negative cycle you can loop for less and less, and $W^{*}$ is $-\infty$ on every pair that touches it.

Bellman (1958) took the other route. Iterate the relaxation over every road, $n-1$ times, and never freeze a label; that is Bellman–Ford, and it survives negative roads for $O(nm)$.

It is the same relaxation with the settled set deleted. The settled set is precisely what non-negativity lets you trust.
