## Four Lines, Four Universes
<ChapterMark minutes={3} tag="the hook" />

A thousand towns put $10^9$ updates inside one triple loop. The same loop answers four different problems, and only the arithmetic changes: $(\min,+)$, $(+,\times)$, $(\mathrm{OR},\mathrm{AND})$, $(\max,+)$.

Here the board is smaller: four towns, five one-way roads, and a tiny grid of numbers. Under standard arithmetic, cell A→D is a distance. Alter two algebraic definitions, and the exact same numbers answer four unrelated branches of computer science.

```
A --1--> B --1--> D
 \        |        ^
  1       1        1
   \      v        |
    ---> C --------+
```

The roads form a matrix $R$, where $R[i][j]$ is the cost of traveling directly from $i$ to $j$, and a dot marks the absence of a road.

```
      A  B  C  D
 A    ·  1  1  ·
 B    ·  ·  1  1
 C    ·  ·  ·  1
 D    ·  ·  ·  ·
```

That grid is the entire input. Focus on cell A→D and consider what value belongs there.

The picture is **the sequence of lenses**: each round lets paths pass through one more vertex, and every lens either takes the new hub or bypasses it.

## The Four-Line Ghost
<ChapterMark minutes={2} tag="the trap" />

Here is the entirety of the algorithm:

```
for k = 1 … n
  for i = 1 … n
    for j = 1 … n
      R[i][j] ← R[i][j] ⊕ R[i][k] ⊗ R[k][j]
```

Notice what is absent: no priority queues, no edge pointers, no graph traversals. Nowhere does the code specify what $\oplus$ and $\otimes$ mean.

Standard teaching obscures this by hardcoding $\oplus = \min$ and $\otimes = +$. That is a single arbitrary choice, and every interpretation the algorithm can manifest lives inside that algebraic substitution.

Running Dijkstra from every vertex costs $O(V \cdot E \log V)$ and refuses negative edges. Bellman–Ford from every vertex costs $O(V^2 E)$. These four lines run in $O(V^3)$, accept negative edges, and never ask what the numbers represent.

## The Kleene Star and Semiring Algebras
<ChapterMark minutes={2} tag="the invariant" />

A **semiring** $(S, \oplus, \otimes, 0, 1)$ is an algebraic structure with addition $\oplus$ and multiplication $\otimes$ satisfying four conditions (Golan 1999):

- $(S, \oplus, 0)$ is a commutative monoid with identity $0$.
- $(S, \otimes, 1)$ is a monoid with identity $1$.
- Multiplication distributes over addition: $a \otimes (b \oplus c) = (a \otimes b) \oplus (a \otimes c)$.
- The zero element annihilates under multiplication: $a \otimes 0 = 0 \otimes a = 0$.

The four-line loop requires nothing else. Associativity permits regrouping road chains, distributivity allows branching paths at intermediate vertices, and annihilation ensures missing roads contribute nothing.

A **closed semiring** equips every element with a Kleene star $a^\star$ (Kleene 1951):

$$
a^\star = 1 \oplus a \otimes a^\star = 1 \oplus a^\star \otimes a
$$

When the geometric series converges, $a^\star = 1 \oplus a \oplus a^2 \oplus \cdots$. For an entire matrix $A$, the triple loop computes the matrix closure $A^\star$, the least solution of $X = I \oplus A \otimes X$ (Lehmann 1977). Four choices define the table below:

| semiring | ⊕ | ⊗ | zero | one | the entry $A^\star_{ij}$ means |
|---|---|---|---|---|---|
| $(\min,+)$ | $\min$ | $+$ | $+\infty$ | $0$ | cheapest route |
| $(+,\times)$ | $+$ | $\times$ | $0$ | $1$ | number of routes |
| $(\mathrm{OR},\mathrm{AND})$ | OR | AND | false | true | whether a route exists |
| $(\max,+)$ | $\max$ | $+$ | $-\infty$ | $0$ | longest route |

Each row represents an arithmetic obeying the exact same four axioms. The code executes identically across all four.

## Elimination and the Semiring Inverse
<ChapterMark minutes={2} tag="the algebra" />

**The recurrence.** Let $d^{(k)}_{ij}$ represent the matrix state after admitting the first $k$ vertices as possible intermediates (Warshall 1962; Floyd 1962):

$$
d^{(0)}_{ij} = A_{ij} \oplus \delta_{ij}, \qquad d^{(k)}_{ij} = d^{(k-1)}_{ij} \oplus \bigl( d^{(k-1)}_{ik} \otimes d^{(k-1)}_{kj} \bigr)
$$

Here $\delta_{ij}$ equals $1$ on the diagonal and $0$ elsewhere, representing a zero-length stay. After $n$ rounds, $d^{(n)} = A^\star$.

Round $k$ eliminates vertex $k$ from remaining paths. A path entering $k$ may loop through $k$ arbitrarily many times, forming the star $R_{kk}^{\star} = \delta \oplus R_{kk} \oplus R_{kk}^{2} \oplus \cdots$.

When addition is idempotent ($a \oplus a = a$, as in $\min$, $\max$, and $\text{OR}$), self-loops collapse to $\delta \oplus R_{kk}$. Real addition is non-idempotent ($1 + 1 = 2$), making each loop a distinct path, where the star becomes the geometric series $\frac{1}{1 - R_{kk}}$.

**Four readings of this grid.** Inspect cell A→D after closure:

| reading | A→D | the number is |
|---|---|---|
| $(\min,+)$ | 2 | the fewest roads on a route |
| $(\max,+)$ | 3 | the most roads on a route |
| $(\mathrm{OR},\mathrm{AND})$ | 1 (true) | whether D is reachable |
| $(+,\times)$ | 3 | how many distinct routes |

Under $(\max,+)$ and $(+,\times)$, cell A→D prints 3, yet they count different concepts: three edges along the longest path versus three distinct paths. Every semiring panel agrees with its row, cell for cell.

**Matrix inversion.** Over real numbers under $(+, \times)$ on an acyclic graph, the closure is the classic Neumann series:

$$
A^\star = I + A + A^2 + A^3 + \cdots = (I - A)^{-1}
$$

The four-line loop is simply Gaussian elimination computing a matrix inverse in a semiring (Lehmann 1977). Shortest paths, path counts, connectivity, and longest routes are all the identical matrix inverse.

## The Many Faces of the Closure
<ChapterMark minutes={2} tag="systems" />

**Shortest paths.** $(\min,+)$ is Floyd's 1962 formulation, solving all-pairs distances in cubic time. Negative edge weights are supported; a negative diagonal after round $n$ flags a negative cycle.

**Reachability.** $(\mathrm{OR},\mathrm{AND})$ is Warshall's 1962 transitive closure. Relational databases evaluate graph queries with it, and compiler build tools compute dependency closures.

**Maximum-likelihood paths.** Viterbi decoding of hidden Markov models uses $(\max,\times)$; taking logarithms converts it to $(\max,+)$. The identical recurrence powers speech recognition and genomic parsing.

**Capacity and bottleneck.** The bottleneck algebra $(\max,\min)$ maximizes the minimal edge capacity along a route. This computes maximum-bandwidth paths across communication backbones.

**Counting.** $(+,\times)$ counts walks. While counting walks in a graph with cycles is polynomial, counting *simple* paths without repeated vertices is #P-complete (Valiant 1979).

## The Boundary of Convergence: When the Star Diverges

The closure sums over paths of unbounded length, meaning convergence depends on the algebraic properties of the graph:

| reading | the closure exists exactly when |
|---|---|
| $(\min,+)$ | no cycle has negative total cost; otherwise the sum runs down forever |
| $(\max,+)$ | no cycle has positive total cost; otherwise the sum runs up forever |
| $(+,\times)$ | the grid has no cycle — otherwise there are infinitely many walks |
| $(\mathrm{OR},\mathrm{AND})$ | always; a Boolean cycle adds no new truth |

For $(\min,+)$ and $(\max,+)$, a diagonal entry is $\delta$ unless a cycle pays off, making the star collapse. For $(+,\times)$, the star is a geometric series that diverges the moment a cycle exists.
