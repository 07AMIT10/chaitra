## The Tour vs. The Level Metric

Textbooks commonly teach breadth-first search as a simple recipe: insert the source into a FIFO queue, pop the front, and enqueue unvisited neighbours. That procedural description conceals the true mathematical object.

The specific order in which vertices emerge from the queue is an arbitrary artefact of tie-breaking and neighbour indexing. What remains absolutely fixed across every valid run is the integer label assigned to each vertex.

Read the canvas as computing an exact metric tensor rather than a traversal tour. Source $S$ receives 0, while subsequent vertices receive their geodesic hop distance from the spark.

## The Geodesic Metric and its Fixed Point

Fix source $s$. The **distance** $d(v)$ is the minimum number of edges on any path from $s$ to $v$. The **level set** $L_k = \{v \in V : d(v) = k\}$ partitions reachable vertices into concentric metric spheres.

Every edge $\{u, v\}$ in the graph must obey the Lipschitz triangle inequality:

$$
d(v) \le d(u) + 1 \qquad \text{for every edge } \{u,v\}
$$

This inequality yields Bellman's equation for unweighted graphs, where $N(v)$ denotes the neighbourhood of $v$:

$$
d(s) = 0, \qquad d(v) = 1 + \min_{u \in N(v)} d(u) \quad (v \ne s)
$$

The distance function is the least fixed point of this equation. On the canvas, vertex $G$ connects to neighbours at levels 3, 3, and 2, uniquely fixing its distance at $1 + 2 = 3$.

## The Monotone Queue and König's Parity Theorem

**The two-level queue invariant.** If the vertex at the front of the queue has level $k$, then every vertex currently waiting in the queue has level $k$ or $k+1$.

Because each unweighted edge has length 1, exploring a level-$k$ vertex discovers only neighbours at level $k+1$. The queue remains permanently sorted by distance without requiring any comparison logic.

**Shortest-path trees and parity.** Tree edges form a directed tree where every child sits at depth $d(\text{parent}) + 1$. Non-tree edges can only connect vertices whose levels differ by 0 or 1.

A graph is **bipartite** if and only if no edge connects two vertices at the identical level. If an edge joins two vertices at level $r$, tracing their ancestors back to their lowest common ancestor at level $\ell$ produces an odd cycle of length $2(r - \ell) + 1$.

This constructive observation proves König's theorem (1936): a graph is 2-colourable if and only if it contains no odd cycle. BFS validates bipartiteness in a single linear pass.

## Metric Geodesics and Small-World Clocks

BFS computes the exact geodesic metric of an unweighted graph in $O(V + E)$ time. Rerunning BFS from each vertex computes the complete graph diameter and all-pairs hop counts.

In distributed computing, each BFS level corresponds to one broadcast round or MapReduce pass (Cohen 2009). The eccentricity of a node becomes the physical latency clock of the network.

In social networks, Milgram (1967) demonstrated the 'six degrees of separation' phenomenon: human connection graphs exhibit remarkably small diameters despite having billions of nodes.

## The Geometry of the Wavefront: Memory Bounds

The queue stores the frontier, which spans at most two adjacent levels. Its peak size is determined by the maximum level width of the network rather than total vertices.

- **Lee 1961** — C. Y. Lee, *An algorithm for path connections and its applications*: the same search as wire routing, where each level is a wavefront.

- **Milgram 1967** — *The small world problem*: the measured handful of hops that makes the level count a social fact.
