## The Solitaire Shuffle

Every diff engine finds the longest increasing subsequence of matched line numbers and calls everything outside it an insertion or a deletion. ## The Quadratic Illusion

The naive programmatic strategy tracks a state array: let `dp[i]` denote the length of the longest increasing subsequence terminating at index `i`.

$$
dp[i] = 1 + \max\{\, dp[j] : j < i \text{ and } p_j < p_i \,\}, \qquad dp[i] = 1 \text{ if no such } j \text{ exists.}
$$

Evaluating this recurrence demands scanning every prior position for each element, consuming $O(n^2)$ pairwise comparisons. But this recurrence does not actually care about strings or arrays; it is secretly computing the maximal chain in a geometric order.

## The 2D Dominance Poset

Drop the array index and treat the sequence as a cloud of planar points $(i, p_i)$. Define a partial order $\prec$ by requiring both coordinates to grow simultaneously:

$$
(i, p_i) \prec (j, p_j) \iff i < j \quad\text{and}\quad p_i < p_j
$$

This relation is the intersection of two linear orders—the order of arrival and the order of value—forming a two-dimensional **dominance poset**.

A **chain** in this poset is a collection of mutually comparable points: sorting them by position automatically sorts them in strictly increasing value. An **antichain** is a set of mutually incomparable points: sorting them by position yields a sequence that never ascends ($p_i \ge p_j$ whenever $i < j$).

The **height** of the poset is the size of its largest chain, while its **width** is the size of its largest antichain. In the visualizer above, gold is the maximal chain and blue is the maximal antichain.

## Mirsky, Dilworth, and the Patience Invariant

**Mirsky's Theorem (Mirsky 1971).** In any finite partially ordered set, the height equals the minimum number of antichains needed to cover all elements.

$$
\operatorname{height}(P) = \min\{\, k : P = A_1 \cup \dots \cup A_k, \ \text{each } A_i \text{ an antichain} \,\}
$$

Patience sorting provides a constructive proof of Mirsky's theorem. Deal the cards left to right, placing each card onto the leftmost pile whose visible top is at least the card's value; if no such pile exists, start a new pile to the right.

Every pile formed this way is strictly non-increasing in time order, so each pile is an antichain. Whenever a card lands on pile $k$, it can be linked to the current top of pile $k-1$, carving out an ascending chain whose length matches the pile count.

Because the active pile tops remain strictly sorted, finding the leftmost valid pile costs only one binary search per card. For $n$ cards, patience sorting computes the exact LIS in $O(n \log n)$ time, entirely sidestepping the quadratic recurrence.

What about Dilworth's theorem? It is the dual counterpart to Mirsky's result, not a duplicate.

**Dilworth's Theorem (Dilworth 1950).** In any finite partially ordered set, the width equals the minimum number of chains needed to cover all elements.

$$
\operatorname{width}(P) = \min\{\, k : P = C_1 \cup \dots \cup C_k, \ \text{each } C_i \text{ a chain} \,\}
$$

Mirsky partitions into antichains to reveal the height; Dilworth partitions into chains to reveal the width.

**Erdős–Szekeres Theorem (Erdős & Szekeres 1935).** Every sequence containing more than $(r-1)(s-1)$ distinct elements must contain either an increasing subsequence of length $r$ or a non-increasing subsequence of length $s$.

## Box Stacking, Diff Engines, and Interception

The height of a two-dimensional poset governs real-world systems constrained by dual thresholds.

Box nesting models this directly: box $A$ nests inside box $B$ when both dimensions are strictly smaller, turning maximum tower height into an LIS chain. Similarly, missile defence scheduling uses Mirsky's theorem to calculate the minimum number of non-increasing interception batteries needed to neutralize an inbound missile barrage.

In file comparison algorithms, diff engines locate identical lines between two documents, order them by line number, and find the longest increasing subsequence. The elements outside that LIS identify the exact insertions and deletions.

## Beyond the First Row: Young Tableaux and Random Matrices

Patience sorting reveals just the first row of a richer algebraic structure. Applying the Robinson–Schensted correspondence (Schensted 1961) inserts each number into a Young tableau. The length of the first row $\lambda_1$ equals the LIS, while the length of the first column equals the longest decreasing subsequence.

For random permutations of size $n$, the expected LIS length scales asymptotically as $2\sqrt{n}$ (Vershik & Kerov 1977).

Baik, Deift & Johansson (1999) proved that the fluctuations of the LIS around $2\sqrt{n}$ converge to the Tracy–Widom distribution from random matrix theory. A simple card game connects directly to quantum energy levels.
