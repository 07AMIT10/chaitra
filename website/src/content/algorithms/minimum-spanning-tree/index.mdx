## 1 · The question

Write down the operational statement a first course hands you. Sort the edges by weight, walk the list, keep an edge unless it closes a cycle, stop when you have `n-1` edges. That is already an algorithm, and it is five lines of code.

So the real question is not what to compute. It is why a decision made at step three can never be regretted at step seven, and what has to be true of the *family of edge sets* for that to hold.

Push on the second half and the answer is sharp. There is one axiom that makes greedy exact, and the cheapest edges themselves are not it. The axiom is about how independent sets of different sizes fit inside one another.

## 2 · The real object: bases of the graphic matroid

A matroid $M = (E,\mathcal{I})$ is a finite ground set $E$ together with a family $\mathcal{I}$ of subsets, called independent, satisfying three properties. The empty set is independent; every subset of an independent set is independent; and the exchange axiom below holds.

$$\text{If } A,B\in\mathcal{I} \text{ and } |A| < |B|, \text{ then } \exists\, e\in B\setminus A \text{ with } A\cup\{e\}\in\mathcal{I}. \qquad (\text{Whitney 1935})$$

Whitney introduced these objects in 1935 to abstract what linear dependence in a vector space actually uses. Read the axiom once more: a smaller independent set can always grow by stealing an element from a larger one, without giving anything back.

For a graph, take $E$ to be the edge set and declare an edge set independent when it is acyclic. Then a maximal independent set — a basis — is a spanning tree, and the whole structure is the **graphic matroid** of the graph (Whitney 1935). A minimum spanning tree is nothing more than a minimum-weight basis.

That the acyclicity family satisfies the exchange axiom is worth checking on the object in front of you, because everything downstream rests on it. Suppose the forests $A$ and $B$ satisfy $|A| < |B|$, and count components: $A$ has $n-|A|$ of them, $B$ has $n-|B|$, so $A$ cuts the vertices into strictly more pieces. If every edge of $B$ had both endpoints inside one piece of $A$, then $B$ could hold at most $n - (n-|A|) = |A|$ edges; since $|B| > |A|$, some edge $e$ of $B$ must join two pieces of $A$, and $A\cup\{e\}$ is again a forest.

## 3 · The mathematics: cut, cycle, and the one axiom under them

Two theorems do all the work, and each is a face of Whitney's axiom. The panels above are the place to point at while you read them.

**Cut property.** Split the vertices into two non-empty sides, and let $e$ be a cheapest edge crossing that split. Then some minimum spanning tree contains $e$.

Take any minimum tree $T$. If $e\notin T$, the unique path in $T$ between the endpoints of $e$ crosses the split an odd number of times, so it contains another crossing edge $f\ne e$. Deleting $f$ and inserting $e$ leaves a spanning tree whose weight changes by $w(e)-w(f)\le 0$, so the tree is still minimum, and now it contains $e$.

If $e$ is the **only** cheapest edge across the split, the inequality is strict, and then every minimum tree contains $e$. A forced edge is a cheapest edge that is unique across some split.

**Cycle property.** Let $e$ be an edge of a cycle $C$ that is strictly heavier than every other edge of $C$. Then no minimum spanning tree contains $e$.

Suppose a minimum tree $T$ did contain $e$. Deleting $e$ from $T$ splits it into two components, and the remaining edges of the cycle $C$ must cross that split, so some other cycle edge $f$ reconnects the two components. Then $T-e+f$ is a spanning tree of weight $w(T)-w(e)+w(f)$ — strictly smaller than $w(T)$, which contradicts minimality.

Now read the panels against those two theorems. The triangle **A–B–D** on screen carries weights 1, 2 and 3, so the edge **B–D** is strictly the heaviest edge of that cycle, and no minimum tree contains it.

The two theorems are not two facts. Together they say: an edge is safe when it is light across a cut, and dead when it is heavy around a cycle, and the exchange axiom is the single statement from which both follow.

**Greedy is exact on a matroid.** Sort $E$ by weight, scan, and keep each edge that leaves the kept set independent. The set you end with is a minimum-weight basis (Rado 1957, Edmonds 1971).

Here is the exchange argument that proves it, in four steps. Write the greedy basis as $g_1,\dots,g_r$ in the order greedy chose it, so $w(g_1)\le\cdots\le w(g_r)$, and write any other basis $B$ as $b_1,\dots,b_r$ in increasing weight.

- Fix $i$ and set $A=\{g_1,\dots,g_{i-1}\}$. Then $g_i$ is a lightest edge with $A\cup\{g_i\}$ independent, because any lighter one had been scanned earlier and would have been taken.
- Put $B_i=\{b_1,\dots,b_i\}$. Both $A$ and $B_i$ are independent and $|A| = i-1 < i = |B_i|$, so exchange hands you some $e\in B_i\setminus A$ with $A\cup\{e\}$ independent.
- Therefore $w(g_i)\le w(e)$, and $e$ lies among the $i$ lightest members of $B$, so $w(e)\le w(b_i)$. Hence $w(g_i)\le w(b_i)$ for every $i$.
- Bases of a matroid all have the same size, so summing over $i$ gives $w(g_1)+\cdots+w(g_r)\le w(b_1)+\cdots+w(b_r)$.

Do not read that as a proof about graphs. It never mentions vertices, weights or cuts; it uses the exchange axiom and nothing else. Any matroid-shaped family gets greedy for free.

That is exactly why the hypothesis is worth testing. Here is a family of the same shape that is not a matroid.

- Three items: **a** has value 7 and weight 5, **b** has value 7 and weight 5, **c** has value 8 and weight 6.
- A set of items is independent when its total weight is at most 10.
- Greedy by value takes **c** first, since 8 is the largest value. That leaves room for neither **a** nor **b**, because 6 + 5 exceeds 10. Greedy scores 8.
- The set `{a,b}` weighs 10 and scores 14, against greedy's 8. The optimum more than doubles greedy here.

The exchange axiom fails on precisely that pair. With $A=\{c\}$ and $B=\{a,b\}$ we have $|A| = 1 < 2 = |B|$, and *no* element of $B\setminus A$ can be added to $A$ without breaking the bound. In a matroid that situation cannot arise: the smaller set always has somewhere to grow. Losing the axiom costs you exactness in polynomial time — this family is the 0/1 knapsack problem, and that is NP-hard (Karp 1972).

## 4 · The centrepiece, read properly

Both panels stopped at five edges and total weight 6. Their logs are not the same log.

- Kruskal accepted A–D, B–E, E–F, C–F, then A–B, and rejected D–E, E–C, B–D.
- Prim accepted A–D, A–B, B–E, E–F, C–F, in that order, adding one vertex each time.

The shared **total** is the theorem from section 3, not luck: both routes return a minimum-weight basis, and a minimum weight depends only on the graph. That the two edge *sets* also coincide is weaker and less interesting — it is the shared tie-break talking, and the next prediction shows how thin that agreement is.

The disagreements that remain are about *which* minimum tree, and they happen only where weights tie. Two edges of weight 2 could carry the final connection, **A–B** and **D–E**, and they sit opposite each other on the cycle A–B–E–D–A. That cycle's heaviest edges are exactly those two, so neither is excluded by the cycle property, and neither is forced by a unique-cheapest cut.

What is genuinely fixed is the other direction: four edges — A–D, B–E, E–F, C–F — sit in *every* minimum tree. Each one is the unique cheapest edge across some split, so the cut property pins it. A–D is alone at weight 1 across the split $\{A\}\mid\{B,C,D,E,F\}$, and E–F is alone at weight 1 across $\{A,B,D,E\}\mid\{C,F\}$.

So the graph has four forced edges, one free choice, and two excluded edges. Greedy is exact about the total and silent about everything else.

## 5 · The payoff

Kruskal's inner question — are these two endpoints already in one component — is a partition query, and the answer is not free. Sort the `m` edges for $O(m\log m)$, then spend a `find` per endpoint per edge; with union by rank and path compression that phase costs $O(m\,\alpha(n))$ and vanishes into the sort. The data structure is on [the union–find page](/algorithms/programming/union-find), and this is where it earns its keep.

$$ O(m\log m) \;+\; O(m\,\alpha(n)) \;=\; O(m\log m) $$

Borůvka got there first, in 1926, for the electrification of Moravia; his algorithm lets every component grow simultaneously, which is the reason it still shows up in parallel and distributed settings. Borůvka-style component merging is the standard approach to connectivity in MapReduce (Kiveris and others 2014), and Jarník published the blob-growing route in 1930, twenty-seven years before Prim's paper.

Cut a minimum spanning tree's heaviest $k-1$ edges and you get $k$ clusters — that is single-linkage clustering, exactly (Gower and Ross 1969). Image segmenters use the same greedy merge. Christofides (1976) turned an MST into a travelling-salesman tour costing at most 1.5 times the optimum.

The structure travels further than graphs. Minimum-weight basis is a theorem about any matroid, so the same greedy solves maximum-weight independent sets under other independence rules, and the exchange argument never changes. The two ends of that road are the randomized linear-time MST of Karger, Klein and Tarjan (1995), which guesses the tree's own edges to prune itself, and the weighted matroid intersection problem, which is what happens when one independence system is not enough.

## 6 · Advanced, and skippable

Skip this if you only need one tree.

Borůvka's algorithm merges each component with its own cheapest outgoing edge. It needs no global sort, it needs each component's minimum, and it halves the component count each round — so it runs in $O(m\log n)$ and parallelises almost unchanged.

Getting below that took decades. Chazelle (2000) reached $O(m\,\alpha(m,n))$ deterministic, matching the union–find bound, and Pettie and Ramachandran (2002) gave the optimal deterministic algorithm — optimal in the sense that its running time is the true complexity of the problem, which nobody has written down in closed form.

Matroid *intersection* is the next rung. Ask for a minimum-weight set independent in two matroids at once: the same shape covers bipartite matching, whose edge sets are independent in two partition matroids, and the polynomial algorithm is Edmonds (1979) — with no greedy argument in sight.
